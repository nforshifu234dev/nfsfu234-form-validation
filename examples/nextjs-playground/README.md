# NFSFU234 Form Validation — Next.js Playground

This project is the official **Next.js integration playground** for **@nfsfu234/form-validation**.

It demonstrates how to install, configure and use the package inside a modern Next.js application.

## Features

- Live form validation
- AJAX playground
- Password utilities
- Public API playground
- Package information
- Compatibility checks
- Official installation examples

---

## Getting Started

Clone the repository and install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

to explore the playground.

---

## Installing the Package

```bash
npm install @nfsfu234/form-validation
```

Import it into your project.

```ts
import NFSFU234FormValidation from "@nfsfu234/form-validation";
```
